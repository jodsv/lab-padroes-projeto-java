# Lab Padrões de Projeto em Java

Projeto desenvolvido para o desafio final da DIO aplicando padrões de projeto GoF em Java puro.

## Padrões Implementados:
- **Singleton**: Garantia de instância única do objeto.
- **Strategy**: Alternância de comportamentos do robô em tempo de execução.
- **Facade**: Interface simplificada para integração de subsistemas.
